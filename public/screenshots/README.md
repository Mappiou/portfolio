# Screenshots des apps

Dépose ici un screenshot par app, en **portrait** (ratio idéal ~9:19.5, ex. 1080×2340).
Il s'affiche automatiquement dans le mockup téléphone sur la page principale et la page détail.

Nommage attendu (référencé dans `src/shared/data/projects.ts`) :

| App         | Fichier                  |
| ----------- | ------------------------ |
| Volley Météo | `volley-meteo.png`      |
| Scan2PDF    | `scan2pdf.png`           |
| Triolinguo  | `triolinguo.png`         |
| Torneo      | `torneo.png`             |
| NoScroll    | `noscroll.png`           |

Tant qu'un fichier est absent, le téléphone affiche un placeholder synthétisé (icône + nom + features) au lieu d'une image cassée.
